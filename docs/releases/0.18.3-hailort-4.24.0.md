## Known limitations

- Hailo-8 PCIe was validated on Raspberry Pi 5 ARM64 only; AMD64 Hailo-8
  hardware inference has not been demonstrated.
- Hailo-8L and Hailo-10 hardware are not established as supported by this fork.
- Portable automated hardware-aware validation remains open as
  [issue #5](https://github.com/pmelendez2/frigate/issues/5).
